Special Event Operations operator guide

The application combines current special-event staffing, append-only asset audit history, client-derived movement trails, and ArcGIS Workflow Manager delivery status in one authenticated operational view.

System of record: source staffing, the audit feature layer, and Workflow Manager remain authoritative. Browser settings only change presentation defaults.

Sign in and verify identity

  1. Select Sign in with ArcGIS.
  2. Use an organizational account authorized for the private staffing and audit layers.
  3. Verify your full name and username in the application header before reviewing or exporting data.
  4. Use Sign out when leaving a shared workstation.

Filter and refresh the audit

  1. Choose an event or leave All events.
  2. Set From and To to the audit period you need.
  3. Select Apply. KPIs, movement trails, asset list, and timeline use the same filter window.
  4. Use the header refresh button for an immediate update. Automatic refresh uses the interval selected in Configuration.

Reconstruct movement

Use Play all assets to reconstruct the filtered operational picture without changing the map zoom. The playback-time slider can be moved manually, and speed can be changed from 0.25× to 4×.

Play one asset

  1. Select an asset in the right-side list.
  2. The player resets to the beginning of the selected time window and changes to Play selected asset.
  3. Select Play to animate only that asset’s updates, position, and growing movement trail.
  4. Select the asset again or use Return to filtered extent to restore all-asset playback.
  • Gold arrow: first location in a movement trail.
  • Cyan arrow: latest location in the trail.
  • Distance: client-computed sum of consecutive audited positions with compatible geometry.

Review assets and Workflow Manager delivery

  1. Select an asset in the right panel or select one of its map graphics.
  2. Review the summary and ordered audit timeline.
  3. Check Workflow status and job ID when a change required a Workflow Manager job.
  4. Select Return to filtered extent to clear the asset focus.

“Not required” means that audit record did not require a Workflow Manager job under the configured policy.

Export filtered audit records

Select Export filtered audit CSV to download the audit rows loaded for the current event and time window. Verify the filter window, generation time, and signed-in username before distributing the file.

Troubleshooting

  • Sign-in repeats: allow pop-ups for this site, sign out, and sign in again.
  • No records: clear the event filter, expand the time window, and select Apply.
  • Wrong playback scope: check the highlighted asset and the Playback scope message. Use Return to filtered extent for all assets.
  • No movement arrow: the asset may have only one distinct audited location or arrows may be disabled.
  • Workflow fields are blank: the record may not require a job, or delivery may still be retrying. Refresh before escalating.
  • Settings do not appear: return to the Operations Map and reload it. Settings are stored per browser.

Quick reference

  • Confirm the signed-in user.
  • Select the event and time window.
  • Apply filters before playback.
  • Check KPI reconciliation.
  • Select an asset for its history.
  • Review Workflow status when present.
  • Use Return to filtered extent when finished.
  • Verify filters before CSV export.
  • Sign out on shared workstations.
